# 数据字典（data/stock_daily/hs300_daily.csv）

> 对应《学习路线》2.2 实操练习 3：记录每个字段的含义和数据来源。

## 文件信息

| 项 | 说明 |
|----|------|
| 文件名 | `data/stock_daily/hs300_daily.csv` |
| 数据内容 | 沪深 300 成分股（前 20 只）近 3 年日线行情 |
| 数据来源 | AKShare `stock_zh_a_hist`（优先），Baostock `query_history_k_data_plus`（回退） |
| 复权方式 | 前复权（qfq，AKShare）/ `adjustflag=2`（Baostock 前复权） |
| 频率 | 日线（daily） |
| 股票数量 | 20 只（`TOP_N=20`，完整版可改为 300） |
| 行数 | 14,500 行 |

## 字段说明

| 字段 | 类型 | 单位 | 含义 | 空值说明 |
|------|------|------|------|----------|
| `code` | str | — | 6 位股票代码（如 `600000`），不带交易所前缀 | 无 |
| `date` | datetime | — | 交易日（YYYY-MM-DD） | 无 |
| `open` | float | 元 | 开盘价（前复权） | 停牌期可能缺失 → ffill |
| `high` | float | 元 | 最高价（前复权） | 同上 |
| `low` | float | 元 | 最低价（前复权） | 同上 |
| `close` | float | 元 | 收盘价（前复权） | 同上 |
| `volume` | float | 股 | 成交量 | 停牌期缺失/为 0 → 填 0 |
| `return` | float | — | 日收益率 = `close.pct_change()` | 每只股票首个交易日为 NaN（正常） |
| `nav` | float | — | 累计净值 = `(1+return).cumprod()`，起点 1.0 | 无 |

## 派生字段口径

- `return`：按股票分组对前复权收盘价算 `pct_change()`，即 `今日收盘 / 昨日收盘 - 1`
- `nav`：对 `return` 加 1 后连乘（`cumprod`），首日收益按 0 处理（`fillna(0)`）

## 已知数据问题（清洗前）

| 问题 | 数量 | 说明 |
|------|------|------|
| `volume` 缺失 | 10 行 | 停牌期间（如 `600027` 在 2024-07 一段区间价格走平、无成交） |
| `return` 缺失 | 20 行 | 每只股票首个交易日，属正常现象，无需处理 |
| 重复 / 异常涨跌 / 停牌量=0 | 0 | 本文件为演示数据，其余脏数据类型未出现 |
