# KDJ 指标介绍

KDJ（随机指标，Stochastic Oscillator）本质上是**用「收盘价在 N 日高低区间中的位置」来衡量多空强弱**，再通过两次平滑得到 K、D 两条线，最后由 K、D 组合出更灵敏的 J 线，用来判断超买超卖与金叉死叉。

## 一、RSV（未成熟随机值）

### 定义

RSV 是 KDJ 的「原料」，表示当天收盘价在最近 N 日（最高价~最低价）区间里所处的位置，取值 0~100。

- RSV = 100：收盘价 = N 日最高价，处于区间顶部，极强
- RSV = 0：收盘价 = N 日最低价，处于区间底部，极弱

### 公式

```
RSV = (收盘价 − N 日最低价) / (N 日最高价 − N 日最低价) × 100
```

### 计算例子

计算 9 日 RSV（N=9）
设最近 9 日最高价为 21、最低价为 10，当天收盘价为 18：

```
RSV = (18 − 10) / (21 − 10) × 100 = 8 / 11 × 100 ≈ 72.73
```

RSV≈72.73 表示当天收盘价落在 9 日高低区间的约 73% 处，偏强。

---

## 二、KDJ 的构成

KDJ 由 RSV 经过两次平滑得到，默认参数为 (9, 3, 3)：

```
K = RSV 的 M 日移动平均（M=3，即对 RSV 做一次平滑）
D = K 的 M 日移动平均（再对 K 做一次平滑）
J = 3K − 2D（由 K、D 组合，放大二者的距离，反应更快）
```

对应关系：RSV 是「原料」，K 是 RSV 的一次平滑，D 是 K 的二次平滑，J 是 K、D 的放大组合。

### 三条线的特点

| 线   | 名称   | 特点                                                       |
| ---- | ------ | ---------------------------------------------------------- |
| K    | 快线   | 对 RSV 平滑一次，较灵敏                                     |
| D    | 慢线   | 对 K 再平滑一次，更稳定，是判断金叉死叉的主线               |
| J    | 辅助线 | J = 3K − 2D，反应最快，可超过 100 或低于 0，易钝化          |

---

## 三、常用信号

金叉：K 上穿 D，看涨，尤其在低位（20 以下）金叉更可靠。

死叉：K 下穿 D，看跌，尤其在高位（80 以上）死叉更可靠。

超买：K、D > 80，涨得过多，随时可能回调。

超卖：K、D < 20，跌得过多，随时可能反弹。

J 值极值：J > 100 表示短期严重超买，J < 0 表示短期严重超卖；但 J 波动大，常出现钝化（高位继续涨、低位继续跌），需结合趋势判断。

背离：价格创新高而 KDJ 未创新高 → 顶背离，预示见顶；价格创新低而 KDJ 未创新低 → 底背离，预示见底。

## 四、Python 计算示例

```python
# 9 日 RSV
low_9 = df['low'].rolling(9).min()
high_9 = df['high'].rolling(9).max()
rsv = (df['close'] - low_9) / (high_9 - low_9) * 100
# K、D 为 RSV 的移动平均（手写示例用简单平均；TA-Lib 用 Wilder 平滑）
df['kdj_k'] = rsv.rolling(3).mean()
df['kdj_d'] = df['kdj_k'].rolling(3).mean()
df['kdj_j'] = 3 * df['kdj_k'] - 2 * df['kdj_d']
```

> 本项目 `utils/technical_indicators.py` 的 `kdj()` 直接调用 TA-Lib 的 `STOCH`（默认参数 fastk=9、slowk=3、slowd=3）得到 K、D，再由 `J = 3K − 2D` 手算 J，结果列为 `kdj_k`、`kdj_d`、`kdj_j`；上面代码为手写示范，其中 K、D 的平滑方式（简单平均 vs Wilder 平滑）与 TA-Lib 略有差异。
