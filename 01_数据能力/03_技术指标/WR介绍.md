# WR 指标介绍

WR（Williams %R，威廉指标）本质上是**用「收盘价在 N 日高低区间中的位置」来衡量多空强弱**，再取反映射到 0~-100 区间，用来判断超买超卖与短期反转的动量指标。

## 一、WR 的构成

### 定义

WR 表示当天收盘价在最近 N 日（最高价~最低价）区间里所处的位置，但方向与 RSV 相反，取值 0~-100。

- WR = 0：收盘价 = N 日最高价，处于区间顶部，极强（超买）
- WR = -100：收盘价 = N 日最低价，处于区间底部，极弱（超卖）

### 公式

```
WR = (N 日最高价 − 收盘价) / (N 日最高价 − N 日最低价) × (−100)
```

- 分子：N 日最高价 − 收盘价，表示「收盘价距离区间顶部还有多远」
- 分母：N 日最高价 − N 日最低价，即 N 日价格波动的总区间

### 计算例子

计算 14 日 WR（N=14）
设最近 14 日最高价为 21、最低价为 10，当天收盘价为 18：

```
WR = (21 − 18) / (21 − 10) × (−100) = 3 / 11 × (−100) ≈ −27.27
```

WR≈−27.27 表示当天收盘价落在 14 日高低区间的约 73% 处（靠近顶部），偏强。

### WR 与 RSV 的对应关系

WR 与 KDJ 的 RSV 用的是**同一个「位置」原料**，只是方向相反：

```
WR = RSV − 100
```

| 收盘价位置             | RSV  | WR      | 含义     |
| ---------------------- | ---- | ------- | -------- |
| 等于 N 日最高价（顶部） | 100  | 0       | 极强超买 |
| 区间中间               | 50   | −50     | 多空平衡 |
| 等于 N 日最低价（底部） | 0    | −100    | 极弱超卖 |

---

## 二、常用信号

超买：WR > −20（即 0 ~ −20），涨得过多，随时可能回调，看空信号。

超卖：WR < −80（即 −80 ~ −100），跌得过多，随时可能反弹，看多信号。

50 轴（−50）：WR 在 −50 上方为多头占优，下方为空头占优。

背离：价格创新高而 WR 未创新高 → 顶背离，预示见顶；价格创新低而 WR 未创新低 → 底背离，预示见底。

---

## 三、Python 计算示例

```python
# 14 日 WR
high_14 = df['high'].rolling(14).max()
low_14 = df['low'].rolling(14).min()
df['wr_14'] = (high_14 - df['close']) / (high_14 - low_14) * (-100)
```

> 本项目 `utils/technical_indicators.py` 的 `wr()` 直接调用 TA-Lib 的 `WILLR`，默认周期 14，结果列 `wr_14`；上面代码为手写示范，与 TA-Lib 结果一致。

## 四、常用 WR(6,14) 组合

单看一个周期的 WR 容易误判，实战中常把**短、长两个周期**放在一起看：WR6（灵敏）、WR14（中性）。

| 周期 | 角色 | 特点                                   |
| ---- | ---- | -------------------------------------- |
| WR6  | 快线 | 反应最快，先给出转折信号，但噪声大     |
| WR14 | 慢线 | 较稳定，用来确认方向、过滤假信号       |

### 常用信号

- 短周期先触极值：WR6 先进入超买/超卖区，WR14 随后确认，信号更可靠。
- 双周期共振：WR6 与 WR14 同时进入超买（> −20）或超卖（< −80）区，反转概率更高。
- 长周期定方向：WR14 站上 −50 偏多、跌破 −50 偏空，作为中短期趋势参考。

### Python 计算示例

```python
for n in (6, 14):
    high = df['high'].rolling(n).max()
    low = df['low'].rolling(n).min()
    df[f'wr_{n}'] = (high - df['close']) / (high - low) * (-100)
```

> 判断超买超卖可用 `df['wr_6'] > -20`、`df['wr_14'] < -80` 等布尔条件；双周期共振可用 `(df['wr_6'] > -20) & (df['wr_14'] > -20)` 判断。
