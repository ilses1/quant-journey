# CCI 指标介绍

CCI（Commodity Channel Index，顺势指标）本质上是**衡量「典型价」偏离其平均水平的程度**，通过除以平均绝对偏差做归一化，用来判断超买超卖、突破与趋势强弱的动量指标。

## 一、典型价（TP）

### 定义

CCI 不是只看收盘价，而是用「典型价」（Typical Price）代表一天的价格重心，综合了最高、最低、收盘三个价位。

### 公式

```
TP = (最高价 + 最低价 + 收盘价) / 3
```

---

## 二、CCI 的构成

### 公式

```
CCI = (TP − TP 的 N 日简单平均) / (0.015 × N 日平均绝对偏差)
```

- TP 的 N 日简单平均（MA_TP）：最近 N 日典型价的算术平均，代表「正常水平」
- 平均绝对偏差（MD）：最近 N 日 |TP − MA_TP| 的平均值，代表「正常波动幅度」
- 系数 0.015：Lambert 提出的经验常数，用于把 CCI 大致落在 ±100 区间内

### 含义

- 分子（TP − MA_TP）> 0：当前典型价高于平均水平，价格走强
- 分子 < 0：当前典型价低于平均水平，价格走弱
- 分母（平均绝对偏差）越大，代表波动越大，同样的价差对应更小的 CCI

### 计算例子

计算 14 日 CCI（N=14），设某日 TP=20、MA_TP=18、平均绝对偏差=1.5：

```
CCI = (20 − 18) / (0.015 × 1.5) = 2 / 0.0225 ≈ 88.89
```

CCI≈88.89 表示价格明显强于平均水平，接近超买区。

## 三、常用信号

超买：CCI > 100，

超卖：CCI < −100，

±100 突破：CCI 从下方上穿 +100，视为强势启动，可顺势看多；从上方下穿 −100，视为弱势启动，可顺势看空。

回归 0 轴：CCI 从超买区回落到 +100 以下，是获利了结/离场信号；从超卖区回升到 −100 以上，是空头回补/入场信号。

背离：价格创新高而 CCI 未创新高 → 顶背离，预示见顶；价格创新低而 CCI 未创新低 → 底背离，预示见底。

> CCI 不受 0~100 限制，理论上可无限大/小，因此没有固定上下限，常用 ±100、±200 作为阈值。

---

## 四、Python 计算示例

```python
# 典型价
tp = (df['high'] + df['low'] + df['close']) / 3
# N 日典型价均值与平均绝对偏差
ma_tp = tp.rolling(14).mean()
md = tp.rolling(14).apply(lambda x: (x - x.mean()).abs().mean(), raw=True)
df['cci_14'] = (tp - ma_tp) / (0.015 * md)
```

> 本项目 `utils/technical_indicators.py` 的 `cci()` 直接调用 TA-Lib 的 `CCI`，默认周期 14，结果列 `cci_14`；上面代码为手写示范，与 TA-Lib 结果一致。

## 五、常用 CCI(14,20) 组合

单看一个周期的 CCI 容易误判，实战中常把**短、长两个周期**放在一起看：CCI14（灵敏）、CCI20（稳定）。

| 周期  | 角色 | 特点                             |
| ----- | ---- | -------------------------------- |
| CCI14 | 快线 | 反应较快，先给出转折信号         |
| CCI20 | 慢线 | 更稳定，用来确认方向、过滤假信号 |

### 常用信号

- 短周期先动：CCI14 先突破 ±100，CCI20 随后跟上，信号更可靠。
- 双周期共振：CCI14 与 CCI20 同时进入超买（> 100）或超卖（< −100）区，反转概率更高。
- 长周期定方向：CCI20 站上 0 轴偏多、跌破 0 轴偏空，作为中期趋势参考。

### Python 计算示例

```python
tp = (df['high'] + df['low'] + df['close']) / 3
for n in (14, 20):
    ma_tp = tp.rolling(n).mean()
    md = tp.rolling(n).apply(lambda x: (x - x.mean()).abs().mean(), raw=True)
    df[f'cci_{n}'] = (tp - ma_tp) / (0.015 * md)
```

> 判断超买超卖可用 `df['cci_14'] > 100`、`df['cci_20'] < -100` 等布尔条件；双周期共振可用 `(df['cci_14'] > 100) & (df['cci_20'] > 100)` 判断。
