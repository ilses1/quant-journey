# OBV 指标介绍

OBV（On-Balance Volume，能量潮）本质上是**把成交量「挂靠」到价格涨跌方向上的累积和**，用来判断量价是否配合、验证趋势真伪的量价指标。

## 一、定义与公式

OBV 的规则非常简单：逐日比较收盘价，把当天的成交量带符号地累加到一个总量上。

```
OBV_t = OBV_{t-1} + ΔOBV_t

          +Volume_t  （收盘价 > 昨收，上涨日）
ΔOBV_t =  −Volume_t  （收盘价 < 昨收，下跌日）
          0          （收盘价 = 昨收，平盘日）
```

- 上涨日：认为买盘推动，成交量记为正数，累加。
- 下跌日：认为卖盘主导，成交量记为负数，累减。
- 平盘日：方向不明，当日成交量不参与，OBV 不变。

> 初始值 OBV_0 取 0 即可。OBV 关心的是**走势形态（创新高/新低）**而非绝对数值，所以起点选多少不影响判断。

## 二、计算例子

设某股连续 5 天：

| 日期 | 收盘价 | 较昨收 | 成交量 | ΔOBV  | OBV  |
|------|--------|--------|--------|-------|------|
| D1   | 10.0   | —      | 1000   | +1000 | 1000 |
| D2   | 10.5   | 涨     | 1500   | +1500 | 2500 |
| D3   | 10.3   | 跌     | 1200   | −1200 | 1300 |
| D4   | 10.3   | 平     | 800    | 0     | 1300 |
| D5   | 10.8   | 涨     | 2000   | +2000 | 3300 |

价升量增时 OBV 稳步抬升，说明上涨有成交量配合；若 D3 下跌日成交量放大（如 1500），OBV 会被明显拉低，提示卖压加重。

## 三、常用信号

- **量价配合（趋势确认）**：价格创新高、OBV 同步创新高 → 上涨有量支撑，趋势健康，看多；价格创新低、OBV 同步创新低 → 下跌有量，看空。
- **顶背离**：价格创新高而 OBV 未创新高 → 上涨动能衰竭，量能跟不上，预示见顶。
- **底背离**：价格创新低而 OBV 未创新低 → 抛压减弱，量能不再配合下跌，预示见底。
- **趋势线突破**：OBV 先于价格突破趋势线，常被当作领先信号。
- **注意**：OBV 是**累积量**，绝对数值没有意义，只看相对走势与背离形态。

## 四、Python 计算示例

```python
# 每日涨跌方向（+1 涨 / -1 跌 / 0 平）
direction = (df['close'].diff() > 0).astype(int) - (df['close'].diff() < 0).astype(int)
# OBV = 方向 × 成交量的累积和
df['obv'] = (direction * df['volume']).cumsum()
```

## 五、与相关量价指标的关系

| 指标 | 与 OBV 的关系 |
|------|---------------|
| 资金流量指标 MFI | 同样用「价格方向 × 成交量」，但 MFI 按典型价算正负资金流并归一化到 0~100，可给出超买超卖阈值 |
| 成交量加权均价 VWAP | OBV 看「量能是否推动价格」，VWAP 看「市场平均成本」，配合使用可判断主力的量价意图 |
| 纯成交量 | 纯成交量只看大小，OBV 额外叠加了「方向」，能把量能和趋势方向绑在一起判断 |

> OBV 适合做**确认与背离**，不宜单独作为买卖信号；通常与均线、MACD 等趋势指标配合，判断趋势是否「有量支撑」。
