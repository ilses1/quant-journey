# RSI 指标介绍

RSI（Relative Strength Index，相对强弱指标）本质上是**把一段时间内的涨跌幅压缩到 0~100 区间**，用来衡量买卖双方力量强弱、判断超买超卖的动量指标。

## 一、RS（相对强度）

### 定义

RS 是「N 日内平均涨幅」与「N 日内平均跌幅」的比值，用来比较上涨力量和下跌力量谁更强。

### 公式

```
RS = 平均涨幅 / 平均跌幅
```

- 平均涨幅 = N 日内上涨日的涨幅之和 / N
- 平均跌幅 = N 日内下跌日的跌幅（取绝对值）之和 / N

### 计算例子

计算 5 日 RS（N=5）
设最近 5 天的涨跌分别为：+2、-1、+3、+1、-2

- 平均涨幅 = (2 + 3 + 1) / 5 = 6 / 5 = 1.2
- 平均跌幅 = (1 + 2) / 5 = 3 / 5 = 0.6
- RS = 1.2 / 0.6 = 2

RS=2 表示「涨的力量是跌的力量的 2 倍」，买方明显占优。

---

## 二、RSI 的构成

RSI 把 RS 再做一个映射，压缩到 0~100 之间：

```
RSI = 100 − 100 / (1 + RS)
```

把上面 RS=2 代入：`RSI = 100 − 100/3 ≈ 66.67`。

对应关系：RS 是「原料」，RSI 是把 RS 从 0~∞ 映射到 0~100 的归一化结果。

### RS 与 RSI 的对应关系

| RS（涨幅/跌幅） | RSI  | 含义             |
| --------------- | ---- | ---------------- |
| 0（全跌）       | 0    | 完全没有上涨力量 |
| 1（涨跌持平）   | 50   | 多空平衡         |
| 2               | 66.7 | 买方占优         |
| 3               | 75   | 明显超买         |
| ∞（全涨）       | 100  | 完全没有下跌力量 |

---

## 三、常用信号

超买：RSI > 70，涨得过多，随时可能回调，看空信号。

超卖：RSI < 30，跌得过多，随时可能反弹，看多信号。

50 轴：RSI 在 50 上方为多头占优，下方为空头占优。

背离：价格创新高而 RSI 未创新高 → 顶背离，预示见顶；价格创新低而 RSI 未创新低 → 底背离，预示见底。

---

## 四、Python 计算示例

```python
# 先算每日涨跌
delta = df['close'].diff()
# 涨幅（上涨日取正，其余为 0）与跌幅（下跌日取绝对值，其余为 0）
gain = delta.clip(lower=0)
loss = -delta.clip(upper=0)
# N 日平均涨幅 / 平均跌幅（Wilder 平滑：EMA，alpha=1/N）
avg_gain = gain.ewm(alpha=1/14, adjust=False).mean()
avg_loss = loss.ewm(alpha=1/14, adjust=False).mean()
# RS 与 RSI
rs = avg_gain / avg_loss
df['rsi_14'] = 100 - 100 / (1 + rs)
```

> 本项目 `utils/technical_indicators.py` 的 `rsi()` 直接调用 TA-Lib，默认周期 14，结果列 `rsi_14`；上面代码为手写示范，采用 Wilder 平滑（`alpha=1/N`），与 TA-Lib 结果一致。

## 五、常用 RSI(6,12,24) 组合

单看一个周期的 RSI 容易误判，实战中常把**短、中、长三个周期**放在一起看：RSI6（灵敏）、RSI12（中性）、RSI24（迟钝）。

| 周期  | 角色 | 特点                                         |
| ----- | ---- | -------------------------------------------- |
| RSI6  | 快线 | 反应最快，先给出转折信号，但噪声大、假信号多 |
| RSI12 | 中速 | 平衡灵敏与稳定，常用于金叉死叉判断           |
| RSI24 | 慢线 | 反应最慢，用来确认大趋势方向                 |

### 常用信号

金叉：RSI6 上穿 RSI12，短线转强，看多。

死叉：RSI6 下穿 RSI12，短线转弱，看空。

三线顺排：RSI6 > RSI12 > RSI24，多头排列，强势；反之空头排列。

齐上超买：RSI6、RSI12、RSI24 同时 > 70，涨势过猛，注意回调风险。

齐下超卖：三条线同时 < 30，跌势过深，注意反弹机会。

多周期共振：RSI6/12/24 方向一致（同向上或同向下）时，信号可靠性高于单周期。

### Python 计算示例

```python
for n in (6, 12, 24):
    delta = df['close'].diff()
    gain = delta.clip(lower=0)
    loss = -delta.clip(upper=0)
    avg_gain = gain.ewm(alpha=1/n, adjust=False).mean()
    avg_loss = loss.ewm(alpha=1/n, adjust=False).mean()
    rs = avg_gain / avg_loss
    df[f'rsi_{n}'] = 100 - 100 / (1 + rs)
```

> 判断金叉死叉可用 `df['rsi_6'] > df['rsi_12']` 与前一日的 `shift(1)` 比较得到穿越点；三周期同向可用布尔运算 `(df['rsi_6']>df['rsi_12']) & (df['rsi_12']>df['rsi_24'])` 判断顺排。
