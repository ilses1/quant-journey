# BOLL 指标介绍

BOLL（Bollinger Bands，布林带）本质上是**用「均值 ± 若干倍标准差」给价格画一个动态通道**，用来描述价格围绕均值波动的范围，衡量波动率、判断超买超卖与变盘时机。

## 一、构成

三条线由「中轨（均线）」和「nbdev 倍标准差」拼成：

```
上轨 = 中轨 + nbdev × σ
中轨 = SMA_N = (P_1 + P_2 + ... + P_N) / N
下轨 = 中轨 − nbdev × σ
```

- 中轨：N 日简单移动平均（SMA），代表价格的「中枢」和趋势方向。
- σ：N 日标准差，衡量价格偏离均值的离散程度。波动越大 σ 越大，通道越宽。
- `nbdev`：带宽倍数，即上下轨各距离中轨几倍标准差。

> σ 的计算：TA-Lib 的 `BBANDS` 用**总体标准差（除以 N）**，与 pandas `std(ddof=0)` 一致；默认 `std(ddof=1)` 是样本标准差，结果略有不同。

## 二、常用参数

| 参数 | 常用值 | 说明 |
|------|--------|------|
| 中轨周期 N | 20 | 默认值，对应约一个月的交易日，平滑适中 |
| | 26 | 更长周期，中轨更平滑、趋势更明显，信号偏迟 |
| 标准差倍数 nbdev | 2 | 默认值，约 95% 价格落在带内（正态假设），最通用 |
| | 2.5 | 更宽的带，减少假突破信号，适合中长线 |
| | 1.5 | 更窄的带，信号更灵敏，适合短线 |

- 周期越大，带越平滑、滞后越明显；倍数越大，带越宽、触及上下轨越难。
- 中轨决定「方向」，标准差倍数决定「通道宽容度」，两者独立调节。

## 三、常用信号

- 触及上轨：短期可能超买，看回调。
- 触及下轨：短期可能超卖，看反弹。
- 带宽收窄（缩口）：σ 变小、上下轨靠拢，波动极低，常预示**变盘**。
- 带宽扩张（开口）：σ 变大、上下轨张开，趋势启动或加速。
- 沿轨运行：强势单边行情中价格贴着上轨（涨势）或下轨（跌势）走，不宜轻易逆势。
- 中轨方向：中轨向上为多头趋势，向下为空头趋势。

## 四、Python 计算示例

```python
# 中轨：20 日简单移动平均
mid = df['close'].rolling(20).mean()
# 标准差：总体标准差（ddof=0，与 TA-Lib 一致）
std = df['close'].rolling(20).std(ddof=0)
# 上轨 / 下轨：中轨 ± 2 倍标准差
df['boll_up'] = mid + 2 * std
df['boll_mid'] = mid
df['boll_low'] = mid - 2 * std
```

> 本项目 `utils/technical_indicators.py` 的 `boll()` 直接调用 TA-Lib 的 `BBANDS`，默认参数 `timeperiod=20, nbdev=2.0`，结果列 `boll_up`/`boll_mid`/`boll_low`；上面代码为手写示范，两者结果一致。

## 五、衍生指标

- `%B = (收盘价 − 下轨) / (上轨 − 下轨)`：>1 突破上轨、<0 跌破下轨、≈0.5 贴近中轨。
- `带宽 = (上轨 − 下轨) / 中轨`：量化「缩口 / 开口」，作变盘预警。

```python
df['boll_pct_b'] = (df['close'] - df['boll_low']) / (df['boll_up'] - df['boll_low'])
df['boll_bw'] = (df['boll_up'] - df['boll_low']) / df['boll_mid']
```
