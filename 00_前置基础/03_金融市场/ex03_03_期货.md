# 03: 期货基础

期货 = **标准化远期合约**。买方承诺在某个未来日期以约定价格买入标的物，卖方承诺以约定价格卖出。

**A 股四大股指期货（中金所）：**

| 品种     | 代码 | 乘数（元/点） | 1 手名义价值 |
| -------- | ---- | ------------- | ------------ |
| 沪深300  | IF   | 300           | 约 100 万    |
| 中证500  | IC   | 200           | 约 110 万    |
| 中证1000 | IM   | 200           | 约 95 万     |
| 上证50   | IH   | 300           | 约 75 万     |

---

## 保证金与杠杆

期货不要求支付全额，只需缴纳约 10%~15% 的保证金。

**例如**：一手 IF 期货名义价值 126 万，保证金 12%，只需 15.12 万就能控制 126 万市值的资产 → 杠杆约 **8.3 倍**。

| 指数涨跌 | 名义盈亏  | 占保证金比例  |
| -------- | --------- | ------------- |
| +10%     | +12.6 万  | +83%          |
| +5%      | +6.3 万   | +42%          |
| +1%      | +1.26 万  | +8%           |
| 0%       | 0         | 0%            |
| -12%     | -15.12 万 | -100%（爆仓） |

**杠杆是把双刃剑**：涨得快，但跌 12% 就亏光全部保证金。

---

## 逐日盯市

每天收盘后，交易所根据结算价重新核算你的账户：当日盈亏直接记入账户资金，亏损导致保证金不足 → 追加保证金 → 不补就强平。

股票可以"扛着等回本"，期货不行——扛不住就必须平仓，平了再涨回来也与你无关。

---

## 主力合约与换月

期货有到期日（交割日），每个时点同时存在多个不同到期日的合约：

```
IF2503（2025年3月到期）
IF2506（2025年6月到期）
IF2509（2025年9月到期）
```

**主力合约** = 持仓量和成交量最大的合约。接近交割时，市场流动性会自动转移到下一个合约。

**换月对量化的影响**：

- 回测数据需拼接主力连续（不能只用单个合约）
- 换月时两个合约价格有差距，净值会跳空
- 必须在交割前平仓，不能死扛

---

## 基差

**基差 = 现货价格 - 期货价格**

- **正基差（贴水）**：期货 < 现货 → 多头换月有利（低价买入新合约）
- **负基差（升水）**：期货 > 现货 → 多头换月不利（高价买入新合约）

中证 500 期货（IC）长期贴水，买 IC 并换月可赚取基差收益——这是许多中性策略选择 IC 做空的核心原因之一。

---

> 假设你持有 IF2506 多头，快交割了必须换仓到 IF2509：卖掉旧合约，买入新合约。
>
> 升水时（期货 > 现货）：新合约比旧合约贵 → 你卖掉便宜的旧合约，买入贵的新合约 → 换月净亏钱。
>
> 贴水时（期货 < 现货）：新合约比旧合约便宜 → 你卖掉贵的旧合约，买入便宜的新合约 → 换月净赚钱。

## 期货 vs 股票

|          | 股票         | 期货         |
| -------- | ------------ | ------------ |
| 交易制度 | T+1          | T+0          |
| 杠杆     | 1倍(无融资)  | 约 8~10 倍   |
| 做空     | 融券(受限)   | 直接卖开     |
| 最大亏损 | 本金(无杠杆) | 可能超过本金 |
| 到期     | 永续         | 有到期日     |
| 涨跌停   | ±10%/20%     | ±3%~6%       |
