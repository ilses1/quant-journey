# 04: 期权基础

https://blog.csdn.net/wusandaofwy/article/details/162068723?spm=1001.2014.3001.5501

期权 = 一份"权利"，不是"义务"。

- **看涨期权（Call）**：买方有权以约定价格买入标的
- **看跌期权（Put）**：买方有权以约定价格卖出标的

---

## 关键术语

| 术语     | 含义                                          |
| -------- | --------------------------------------------- |
| 行权价   | 期权合约约定的交易价格                        |
| 权利金   | 买方支付给卖方的费用（期权的价格）            |
| 到期日   | 期权失效的日期，到期后权利消失                |
| 内在价值 | 立即行权能赚的部分（股价 - 行权价，至少为 0） |
| 时间价值 | 权利金 - 内在价值。距离到期越远，时间价值越高 |

---

## 四种基本操作

### Buy Call（买看涨）——看大涨

付权利金 5 元/股，行权价 100 元。

| 到期股价 | 行权收益    | 扣权利金后盈亏 |
| -------- | ----------- | -------------- |
| 80       | 0（不行权） | -5             |
| 100      | 0           | -5             |
| 110      | 10          | +5             |
| 120      | 20          | +15            |

**收益无限（股价涨多少赚多少），亏损有限（最多亏权利金）。**

### Buy Put（买看跌）——看大跌

付权利金 4 元/股，行权价 100 元。

| 到期股价 | 行权收益 | 扣权利金后盈亏 |
| -------- | -------- | -------------- |
| 80       | 20       | +16            |
| 90       | 10       | +6             |
| 100      | 0        | -4             |
| 110      | 0        | -4             |

**收益上限≈行权价-权利金，亏损有限。**

### Sell Call / Sell Put（卖方）——看不涨/看不跌

卖方收权利金，盈亏 = 买方盈亏的相反数。买方最多亏权利金，卖方可能亏无限。

## 隐含波动率（Implied Volatility, IV）

从期权的市场价格**反推**出来的"市场对未来波动的预期"。

|         | 历史波动率(HV)     | 隐含波动率(IV)                    |
| ------- | ------------------ | --------------------------------- |
| 来源    | 实际发生的，回头看 | 期权价格反推，看未来              |
| IV > HV | —                  | 期权偏贵 → 卖方有利（做空波动率） |
| IV < HV | —                  | 期权偏便宜 → 买方有利             |

IV 高 → 市场在恐慌（如财报前夕）→ 期权变贵。

## 希腊字母速查

| 字母  | 含义                            | 买方视角                  |
| ----- | ------------------------------- | ------------------------- |
| Delta | 标的涨 1 元，期权价格变动       | Call: 0~1（实值时接近 1） |
| Gamma | Delta 随标的变化的速度          | 期权最敏感的风险指标      |
| Theta | 每天时间流逝，期权贬值多少      | **买方：时间的敌人**      |
| Vega  | IV 每涨 1%，期权价格变多少      | 波动率交易的核心指标      |
| Rho   | 无风险利率每变 1%，期权价格变动 | 短期期权几乎忽略          |

## 期权 vs 股票/期货

|          | 股票 | 期货   | 期权(买方) |
| -------- | ---- | ------ | ---------- |
| 盈亏特征 | 线性 | 线性   | **非线性** |
| 最大亏损 | 本金 | 超本金 | 权利金     |
| 做空方式 | 融券 | 卖开   | 买 Put     |

## 期权开户门槛

A 股场内期权有三道硬性门槛，缺一不可：

**1. 资金门槛：50 万**

申请开通前 20 个交易日，日均证券资产不低于 **50 万元**（股票 + 现金 + 基金等合计）。

**2. 交易经验 + 考试**

- 至少半年证券交易经验
- 在券商现场参加期权知识测试，80 分及格

**3. 模拟交易记录**

在券商模拟系统里完成至少 **10 笔买入、10 笔卖出**，四种基本操作（买 Call / 卖 Call / 买 Put / 卖 Put）都要覆盖到。

---

### 权限分级（不是开户就能做所有操作）

| 级别 | 能做啥                                   | 适用人群       |
| ---- | ---------------------------------------- | -------------- |
| 一级 | 备兑开仓 + 保险策略（持有股票再卖 Call） | 刚开户         |
| 二级 | 一级 + 买入开仓（买 Call / 买 Put）      | 攒够交易记录后 |
| 三级 | 二级 + 卖出开仓（裸卖 Call / 裸卖 Put）  | 经验丰富后     |

### 持仓限额

| 等级 | 权利仓限额 | 总持仓限额 |
| ---- | ---------- | ---------- |
| 初级 | ≤ 20 张    | ≤ 50 张    |
| 中级 | ≤ 100 张   | ≤ 200 张   |
| 高级 | ≤ 1000 张  | ≤ 2000 张  |

限额随成交量和时间逐步提升，新手一开始最多持仓 50 张。
