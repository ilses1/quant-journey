# 01: 股票市场核心概念

---

## 复权（Price Adjustment）

股票分红送股时，股价会"除权"——每股分红 1 元，股价就从 10 元跳到 9 元。如果不修正：

- K 线图上出现断裂
- 均线、MACD 等指标在除权日附近全部失效
- "我 10 块买的怎么突然变 9 块了？"——其实是你拿到了 1 元分红

> 完全不分红、不送股、不拆股的品种，三种复权方式的数值一模一样——复权因子始终为 1，乘不乘没区别。

> 但实际中：
> 个股：A 股几乎所有股票上市几年后都会分红或送转。只有上市不久、从未分红的次新股才"三线重合"。
> ETF：其实是会分红的——ETF 持有的底层股票分红后会累计到基金净值里，然后定期分给持有人。比如 510300（沪深300 ETF）就定期分红，所以 ETF 也需要复权。

> 所以回测时别纠结——一律用前复权就行，有除权它帮你抹平，没除权它不改变数据，零代价

**三种复权方式：**

| 方式   | 做法                                      | 最新价     | 上市首日价 | 用途                             |
| ------ | ----------------------------------------- | ---------- | ---------- | -------------------------------- |
| 不复权 | 不修正                                    | 真实成交价 | 真实成交价 | 看历史实际成交价                 |
| 前复权 | 以最新价为锚，历史全部价格 × 累计复权因子 | 不变       | 被压得很低 | **回测首选**——信号基于最新价生成 |
| 后复权 | 以首日价为锚，后续全部价格 × 累计复权因子 | 被抬得很高 | 不变       | 计算上市以来真实累计收益率       |

> 前复权和后复权都计算了股票上市以来**所有**的除权除息次数，不是只调最近一次。
>
> 为什么有时前复权近一两年和不复权差不多？因为前复权的累计复权因子是从最近一期除权倒推回去的——如果只看靠近期末的数据，累计因子接近 1，调不调差别不大。而后复权因子从上市日累积至今，可能已翻了数倍甚至数十倍，所以差值非常显眼。两者都是对的，只是"谁来当不动的锚点"不同。

**量化铁律：回测必须用前复权或后复权，不能用不复权。**

## T+1 制度

当天买入的股票最早下一个交易日才能卖出（美股是 T+0）。

**对策略的影响：**

- 日内反转策略（当买当卖）不可行
- 上午买入信号 → 收盘价不能退出 → 必须次日 → 面临隔夜跳空风险
- 周五买入 → 周一才能卖 → 中间隔一个周末
- 利空消息盘中出 → 你刚买的仓位只能眼睁睁看着跌，卖不掉

## 涨跌停限制

| 市场              | 涨跌停幅度 |
| ----------------- | ---------- |
| 主板（60/00开头） | ±10%       |
| 创业板（30开头）  | ±20%       |
| 科创板（68开头）  | ±20%       |
| ST 股             | ±5%        |
| 新股上市前 5 天   | 无限制     |

**对策略的影响：**

- 触及涨停 → 买不进去（无量涨停）
- 触及跌停 → 卖不出去（流动性归零）
- 连续跌停是风控噩梦：想止损但根本卖不掉，等能卖时已腰斩
- 回测里必须标记涨跌停日的订单为"未成交"

## 订单类型

### 限价单

指定价格，不优于此价不成交。"我只出 10 块，多了不买"。

- 优点：控制成交成本，不被高位接盘
- 缺点：可能永远不成交（价格没到你的限价）

### 市价单

不指定价格，按当前最优对手价立即成交。

- 优点：保证成交
- 缺点：成交价不确定；流动性差时价格可能很差
- A 股限制：市价单必须在特定挡位内选择

### 止损单（A 股原生不支持，需程序模拟）

- 止损卖出：跌破某价格 → 自动市价卖出限制亏损
- 止损买入：涨破某价格 → 自动市价买入追突破

## 集合竞价 vs 连续竞价

### 集合竞价（开盘/收盘前）

**时间**：9:15~9:25（开盘），14:57~15:00（收盘）

系统收集所有买入卖出委托，用"最大成交量原则"算出一个价格作为开盘/收盘价——能成交最多的价格。所有以这个价格或更优价格挂的单都在此价成交。

**意义**：发现均衡价格，避免开盘瞬间剧烈波动。

| 时间段    | 规则                   |
| --------- | ---------------------- |
| 9:15~9:20 | 可挂可撤（虚假挂单多） |
| 9:20~9:25 | 只挂不撤（真实供需）   |
| 9:25      | 开出开盘价             |

### 连续竞价（盘中）

9:30~15:00，买一和卖一匹配就成交。原则：**价格优先、时间优先**——出价高的买方先成交，同价看谁先挂。

## 交易成本

量化回测忽略交易成本 = 收益严重高估。

### A 股实际费率

| 费用   | 费率          | 收取方向 | 备注                |
| ------ | ------------- | -------- | ------------------- |
| 佣金   | 万1~万2.5     | 买卖双向 | 最低 5 元/笔        |
| 印花税 | 万5(0.05%)    | 仅卖出   | 2024年8月减半征收   |
| 过户费 | 万0.1(0.001%) | 买卖双向 | 仅上海市场（6开头） |

### 隐性成本（回测中无法精确计算但必须考虑）

| 成本     | 说明                                                             |
| -------- | ---------------------------------------------------------------- |
| 滑点     | 实际成交价偏离委托价。限价单可能不成交，市价单可能比预期价差     |
| 冲击成本 | 大订单推动价格移动。买 1 万股 vs 买 100 万股，后者会吃掉多档挂单 |

### 频率 vs 成本敏感性

| 频率   | 年化成本 | 影响             |
| ------ | -------- | ---------------- |
| 月调仓 | ~0.5%    | 影响较小         |
| 周调仓 | ~2-3%    | 必须关注         |
| 日调仓 | ~30-50%  | 成本决定策略生死 |

## 行情数据层级

| 层级  | 频率     | 单股单日条数 | 适用策略        | 数据量/年 |
| ----- | -------- | ------------ | --------------- | --------- |
| tick  | 逐笔成交 | ~100,000     | 高频做市/订单流 | ~TB       |
| 1min  | 每分钟   | ~240         | 盘中择时/突破   | ~GB       |
| 5min  | 每5分钟  | ~48          | 日内/隔夜       | ~MB       |
| daily | 每日     | 1            | 中低频多因子    | ~KB       |

**回测精度的 trade-off**：日线最快但有偏差，分钟线精确但量 ×240，tick 最精确但量 ×2000+。大部分个人策略日线足够。
