# 02 数学统计 — 依赖库

本章需要以下 Python 库：

## 已安装（ex01 已用）

| 库 | 用途 |
|---|---|
| `numpy` | 向量化数学运算、随机数生成、矩阵计算 |
| `pandas` | 时序数据处理、统计分析 |
| `matplotlib` | 数据可视化 |

## 本章新增

| 库 | 用途 | 安装 |
|---|---|---|
| `scipy` | 统计检验（t 检验、正态性检验、偏度/峰度） | `pip install scipy` |
| `statsmodels` | 计量经济学模型（OLS 回归、ADF 平稳性检验、ACF/PACF） | `pip install statsmodels` |

## 一键安装

```bash
pip install scipy statsmodels
```
