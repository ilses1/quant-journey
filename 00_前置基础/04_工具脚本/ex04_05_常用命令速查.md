# 05: 常用命令速查

---

## conda 命令

| 操作 | 命令 |
|------|------|
| 创建环境 | `conda create -n 环境名 python=3.10` |
| 激活环境 | `conda activate 环境名` |
| 退出环境 | `conda deactivate` |
| 查看环境列表 | `conda env list` |
| 删除环境 | `conda remove -n 环境名 --all` |
| 查看已安装包 | `conda list` |
| 安装包 | `conda install 包名` |
| 卸载包 | `conda remove 包名` |
| 更新 conda | `conda update conda` |

---

## pip 命令

| 操作 | 命令 |
|------|------|
| 安装包 | `pip install 包名` |
| 指定版本 | `pip install 包名==1.2.3` |
| 升级包 | `pip install --upgrade 包名` |
| 卸载包 | `pip uninstall 包名` |
| 查看已安装 | `pip list` |
| 查看过期的包 | `pip list --outdated` |
| 导出依赖 | `pip freeze > requirements.txt` |
| 批量安装 | `pip install -r requirements.txt` |
| 查看包信息 | `pip show 包名` |

## Git 命令

### 基础操作

| 操作 | 命令 |
|------|------|
| 初始化仓库 | `git init` |
| 克隆仓库 | `git clone 仓库地址` |
| 查看状态 | `git status` |
| 添加到暂存区 | `git add 文件名` 或 `git add .` |
| 提交 | `git commit -m "提交说明"` |
| 推送 | `git push origin 分支名` |
| 拉取 | `git pull origin 分支名` |

### 查看历史

| 操作 | 命令 |
|------|------|
| 提交日志 | `git log --oneline -10` |
| 带分支图 | `git log --graph --oneline` |
| 查看某次提交详情 | `git show 版本号` |
| 查看修改内容（未暂存） | `git diff` |
| 查看修改内容（已暂存） | `git diff --staged` |

### 分支操作

| 操作 | 命令 |
|------|------|
| 查看分支 | `git branch` |
| 创建分支 | `git branch 分支名` |
| 切换分支 | `git checkout 分支名` |
| 创建+切换 | `git checkout -b 分支名` |
| 合并分支 | `git merge 来源分支` |
| 删除分支 | `git branch -d 分支名` |

### 撤销与回退

| 操作 | 命令 |
|------|------|
| 取消暂存 | `git reset HEAD 文件名` |
| 丢弃修改 | `git checkout -- 文件名` |
| 修改最近提交信息 | `git commit --amend -m "新信息"` |
| 回退到某版本 | `git checkout 版本号 -- 文件名` |

## PowerShell 常用命令

量化开发大量操作在终端里完成，这些 Windows 命令要熟：

| 操作 | 命令 | Linux/Mac 等价 |
|------|------|:---:|
| 当前目录 | `Get-Location` 或 `pwd` | `pwd` |
| 列出文件 | `Get-ChildItem` 或 `ls` | `ls` |
| 切换目录 | `Set-Location 路径` 或 `cd 路径` | `cd` |
| 创建目录 | `New-Item -ItemType Directory 目录名` 或 `mkdir 目录名` | `mkdir` |
| 删除文件 | `Remove-Item 文件名` 或 `rm 文件名` | `rm` |
| 删除目录 | `Remove-Item -Recurse 目录名` | `rm -r` |
| 复制文件 | `Copy-Item 源 目标` 或 `cp 源 目标` | `cp` |
| 移动文件 | `Move-Item 源 目标` 或 `mv 源 目标` | `mv` |
| 查看文件内容 | `Get-Content 文件名` 或 `cat 文件名` | `cat` |
| 清屏 | `Clear-Host` 或 `cls` | `clear` |
| 查看命令历史 | `Get-History` 或 `h` | `history` |

## Python 常用脚本命令

```powershell
python 脚本名.py           # 运行脚本
python -m pip install ...  # 用当前环境的 pip 安装包
python -c "代码"           # 直接在命令行执行一行 Python
```

### IPython（比普通 Python 交互环境强）

```powershell
ipython                     # 进入增强交互环境
```

IPython 特点：Tab 补全、`?` 查看文档、`%timeit` 测速、魔法命令。

```
In [1]: import pandas as pd
In [2]: pd.read_csv?        # 查看函数文档
In [3]: %timeit sum(range(1000000))  # 测代码执行时间
```


## 环境诊断命令

遇到问题时，先执行这些命令确认环境状态：

```powershell
python --version          # Python 版本对不对？
pip --version             # pip 是从哪来的？
conda info --envs         # 有哪些环境？当前激活的是哪个？
where python              # 系统里装了哪几个 Python？
```

> `where python` 在新装多版本 Python 时特别有用——有时候终端调用的不是你期望的那个 Python。
