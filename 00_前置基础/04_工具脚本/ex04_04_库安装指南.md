### Tushare 注册与 Token

Tushare 需要注册后才能使用。流程：
1. 访问 [https://tushare.pro](https://tushare.pro) 注册
2. 登录后 → "个人主页" → "接口TOKEN" 复制 token
3. 代码中设置：

```python
import tushare as ts
ts.set_token("你的token")
pro = ts.pro_api()
```

不同积分等级对应不同接口权限。基础积分（120 分）足以拉取日线行情和基础财务数据——对学习阶段完全够用。

## 技术指标库

```powershell
pip install ta-lib
```

**TA-Lib** 是量化标配的技术指标库，包含 150+ 种指标（MA、MACD、RSI、布林带、ATR 等），底层用 C 实现，速度快。

### Windows 安装注意事项

TA-Lib 在 Windows 上安装可能报错（缺少 C 编译环境）。解决方案：

**方案1（推荐）：下载预编译包**
访问 [https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib](https://www.lfd.uci.edu/~gohlke/pythonlibs/#ta-lib)，
下载对应 Python 版本的 `.whl` 文件，然后本地安装：

```powershell
pip install TA_Lib‑0.4.28‑cp310‑cp310‑win_amd64.whl
```

> `cp310` = Python 3.10，`win_amd64` = Windows 64位。根据自己的 Python 版本选择。

**方案2：用 conda 安装**
```powershell
conda install -c conda-forge ta-lib
```

**方案3：纯 Python 替代（降低入门门槛）**

如果 TA-Lib 安装失败且暂时不想折腾，可以用 `pandas-ta`：
```powershell
pip install pandas-ta
```

```python
import pandas_ta as ta
df.ta.sma(length=20, append=True)   # 均线
df.ta.rsi(length=14, append=True)   # RSI
df.ta.macd(append=True)             # MACD
```

`pandas-ta` 纯 Python 实现，安装零依赖，但计算速度比 TA-Lib 慢（大部分场景体感不明显）。

## 版本选择建议

| 组件 | 推荐版本 | 原因 |
|------|----------|------|
| Python | 3.10 或 3.11 | 生态最成熟，几乎所有量化库都支持 |
| NumPy | 1.x（最新） | 2.x 仍有部分库未适配 |
| Pandas | 2.x（最新） | 稳定，Parquet 支持好 |
| Backtrader | 1.9.x | 最新稳定版 |

> 不要追最新版 Python（如 3.13）。很多量化库的维护者更新没那么快，新版本可能出现兼容问题。
