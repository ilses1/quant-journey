## 三、必须搞懂的两个概念

### 1. 复权（前复权 / 后复权 / 不复权）

股票分红送股后价格会"跳空下跌"，但这个跌不是真的跌。

- **不复权**：按交易所真实成交价，除权日会出现假暴跌
- **前复权(qfq)**：以**现在**为基准，把历史价格往回折算。适合直接算收益率、画净值曲线
- **后复权(hfq)**：以**上市日**为基准，把之后价格往前折算。适合看长期真实涨幅

> 量化计算收益率**统一用前复权**，否则分红日会算出假的 -20% 大跌。

### 2. 股票代码前缀（不同源要求不同）

| 数据源 | 代码写法 |
|--------|----------|
| AKShare | 纯 6 位数字 `600519`（不用前缀） |
| Baostock | 带交易所 `sh.600519` / `sz.000001`（6 开头沪市，其余深市） |
| Tushare | 带后缀 `600519.SH` / `000001.SZ` |

`ex01` 走通完整流程：
1. 取沪深 300 成分股列表 → 2. 逐只拉近 3 年日线 → 3. 算日收益率 → 4. 画累计收益曲线 → 5. 存 CSV

关键代码记忆点：

```python
# 日收益率：按股票分组后对收盘价求涨跌幅
data["return"] = data.groupby("code")["close"].pct_change()

# 净值曲线 = 收益率 +1 后连乘
data["nav"] = data.groupby("code")["return"].transform(lambda r: (1 + r.fillna(0)).cumprod())

# 长表转宽表（每只股票一列），方便画图和算截面
data.pivot(index="date", columns="code", values="nav")
```

## 五、踩过的坑

1. **AKShare 在新版 Python（如 3.14）下访问东财/新浪接口报 SSL 错误** —— 这是 TLS 握手被服务端拒绝，不是代码问题。解决：改用 Baostock（走 socket 不受影响），或降级 Python 到 3.10/3.11。
2. **Tushare 免费 token 积分会过期** —— `pro.daily` 返回空表多半是积分不够了，去 tushare.pro 重新做任务攒分。
3. **下载几百只股票要限速** —— 循环里加 `time.sleep(0.1)`，避免被数据源封 IP。
